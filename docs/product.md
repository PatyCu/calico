# Product

Calico is an AI workspace, beginning with conversations. See [PROGRESS](../PROGRESS.md) for milestones and completion status.

## Current capabilities

The New Conversation screen sends a sentence to the backend and displays its echo reply. It supports a waiting state and retry after errors, plus backend connectivity status and manual connection checks. Messages are not saved. Appearance supports Light, Dark, and System.

## Planned scope

The MVP centers on conversations, agent tools, artifacts, attachments, and external connections. Artifacts hold current content only; versioning is outside the MVP. Milestone sequencing belongs in [PROGRESS](../PROGRESS.md).
